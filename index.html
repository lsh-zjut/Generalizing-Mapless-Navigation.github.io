Generalizing Topological-Image-Guided Navigation: Achieving Robust Obstacle Avoidance Using General Navigation Models

Abstract

While pretrained visual navigation models provide useful waypoint guidance, their outputs are often coarse and geometry agnostic. In particular, they do not explicitly account for local obstacles, robot motion constraints, or command feasibility. To bridge this gap, this paper proposes a hierarchical modular navigation framework under topological visual guidance that combines a general navigation model with physically grounded local planning. The framework contains three core components. (1) A hierarchical architecture connects visual waypoint prediction with physical execution. (2) A waypoint-conditioned interface bridges position-only visual guidance and local planning by deriving target headings, enforcing footprint-aware LiDAR feasibility, and optimizing commands for progress and continuity. (3) We evaluate the proposed framework through extensive simulation and real-world experiments across diverse robotic platforms, benchmarking it against established local planners. The complete system is guided by an ordered sequence of RGB topological keyframe images prepared for each route, with topological localization providing route progress. Local execution does not require a metric map, metric pose estimate, or SLAM pose graph. Extensive evaluations across IR-Sim, Gazebo, and real world platforms show encouraging improvements in the tested navigation tasks. The results indicate that waypoint guidance, local geometry, and robot motion constraints can be connected through a modular interface for practical deployment.

System Overview

  • A hierarchical navigation framework is developed to connect visual waypoint guidance with local execution that does not require a metric map. The complete system uses an RGB topological map and topological localization for route progress.
  • A waypoint-conditioned local execution interface connects visual guidance based on position alone to local planning for the target robot. The local planner converts each waypoint into a target heading, applies LiDAR feasibility checks using the robot footprint, and scores feasible commands for progress and continuity.
  • Simulation and real-world experiments across multiple platforms are conducted to evaluate the framework in obstacle avoidance tasks and to analyze its performance against traditional local planners under matched deployment settings.
